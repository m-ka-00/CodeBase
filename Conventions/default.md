# Default
Base conventions applied across contexts, only preceded by syntax constraints

## General
### Names
- General:      1 English non-compound word consisting of only letters
    [ꭵ](## "Applies to everything")
- Containers:   Capitalized
    [ꭵ](## "Parent/base structures: Folders, Classes, etc")
- Contents:     Lowercase
    [ꭵ](## "Child/instance structures: Files, Functions, Objects, Intances, Varibles")
### Architecture
- Design:       Modular & Object-Oriented
- Scope:        No global variables/functions, hardcoded values stored externally in serialized data formats
### Placement
- Indention:    Tabs (Size: 4 spaces)
- Comments:     Same line as the code being described
- Operators:    Horizontally align when adjacent, same type, & same nesting depth
